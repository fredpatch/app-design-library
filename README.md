# App Design Library

Reusable design system, component library, pattern library, theme collection,
and AI prompt library for Fredpatch applications.

## Initial consumers

- Prestix
- SICOT

## Workspace structure

- `apps/storybook`: component and pattern catalog
- `packages/tokens`: semantic design tokens
- `packages/themes`: application themes
- `packages/ui`: reusable UI components
- `packages/patterns`: reusable page and workflow patterns
- `packages/prompts`: design generation, adaptation, review, and refinement prompts
- `docs`: architecture, contribution, and extraction documentation

## Status

This repository currently contains scaffolding and foundation contracts only.
React component implementations are intentionally deferred until the public APIs
and token system are validated.
