# Adapt a library pattern to an application

Act as a senior product designer and frontend architect.

1. Inspect the target project's tokens, shared components, layouts, and similar screens.
2. Identify existing components that can be reused.
3. Do not create duplicate primitives or patterns.
4. Map business statuses to semantic tones inside the application.
5. Preserve the application's selected theme and density.
6. Report proposed files and component boundaries.
7. Do not implement until the plan is approved.
